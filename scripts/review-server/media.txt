# What the App Review demo server holds, one line per title, fields separated by | (no spaces round them):
#
#   kind|archive item|file in the item|path under media/|title|year|license|license URL|credit|overview
#
# kind is movie, show (the series itself: no file, just its folder; "frame" in the file field cuts a
# poster from its first episode, for a series no metadata provider knows), episode or album (every
# original MP3 in the item, and its cover image, into the folder). fetch-media.sh downloads each file
# from https://archive.org/download/<item>/<file> and writes media/LICENSES.md from these lines.
# docs/release/review-server.md says why each title is legally free to stream. Keep it that way:
# only public domain or Creative Commons Attribution, nothing with a NonCommercial or
# NoDerivatives clause of doubtful provenance, and nothing whose copyright status you'd have to argue.
